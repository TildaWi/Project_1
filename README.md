## ✏️ 프로젝트 회고 (Learned Lessons)

- **단순히 '고장' 발생 후 대응하는 시스템**의 한계를 체감  
- 정비 효율화에는 **공간(자치구) + 시간(신고 집중 시간) + 부품**에 따른 대응이 모두 필요함  
- 데이터 기반으로 정비 전략을 시각화하고 전달하는 것이 **운영팀과의 커뮤니케이션 핵심 포인트**임
